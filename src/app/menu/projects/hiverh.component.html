Trabajo académico en equipo

HiveRH

Una API REST para la gestión interna de recursos humanos.

Participé en el desarrollo grupal de un MVP académico para organizar empleados y procesos de RR. HH.: estructura organizacional, licencias, vacaciones, certificados y liquidaciones de sueldo.

Trabajo en equipo sobre un dominio de negocio, persistencia relacional, autenticación y reglas de acceso.

  • Java
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • MySQL
  • JWT
  • Swagger / OpenAPI
Ver repositorio de HiveRH ↗

Del dominio a la API

Modelado y persistencia

Entidades relacionadas para empleados, sucursales, departamentos y puestos. Módulos organizados por funcionalidad, con controladores, servicios, repositorios y DTOs.

Autenticación y acceso

JWT con Spring Security. Roles ADMIN, RRHH y EMPLOYEE, y comprobaciones de acceso a recursos propios, como las liquidaciones de un empleado.

Reglas y contratos

Validaciones de negocio, como evitar dos liquidaciones para un empleado en el mismo mes. Endpoints documentados con Swagger/OpenAPI.
