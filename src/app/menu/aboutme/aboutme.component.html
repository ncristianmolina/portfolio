03 / Sobre mí

Primero, entender el problema

Me interesa entender un proceso antes de convertirlo en código: qué información necesita, qué reglas lo condicionan y qué debería pasar cuando algo falla.

Quiero seguir desarrollándome en Java y Spring Boot, con foco en modelar dominios de negocio y escribir software que sea fácil de mantener.

Backend
PHP y arquitectura modular en Rubicom. Java 21, Spring Boot y JPA / Hibernate en proyectos personales y académicos.
Frontend
JavaScript, jQuery, AJAX y Bootstrap en el trabajo. HTML, CSS, Angular y TypeScript en proyectos y aprendizaje.
Datos
PostgreSQL y MySQL en proyectos. SQL Server y bases de datos relacionales en formación.
Herramientas
Git, GitHub, Maven y Docker en proyectos. Análisis de incidencias, exportaciones a Excel y JSON en el trabajo.
