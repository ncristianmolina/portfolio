TurnApp

Gestión de turnos para empresas y sucursales.

Diseño una arquitectura SaaS para organizar turnos en negocios con múltiples empresas y sucursales. Estoy construyendo el backend con Java y Spring Boot, con PostgreSQL para la persistencia y Angular previsto para la interfaz.
