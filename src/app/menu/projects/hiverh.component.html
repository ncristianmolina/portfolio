HiveRH

Una API REST para procesos de RR. HH.

Participé en el desarrollo grupal de un MVP para gestionar empleados, estructura organizacional, licencias, vacaciones, certificados y liquidaciones de sueldo.

  • Java
  • Spring Boot
  • MySQL

API implementada. Producción prevista y frontend en Angular planificado como parte de la cursada.

Ver repositorio de HiveRH ↗
Dominio y persistencia
Relaciones entre empleados, sucursales, departamentos y puestos con Spring Data JPA.
Autenticación y acceso
JWT con Spring Security. Roles ADMIN, RRHH y EMPLOYEE, con comprobaciones de acceso a recursos propios.
Reglas de negocio
Validaciones como evitar dos liquidaciones del mismo empleado en un mes. Contratos documentados con Swagger y OpenAPI.
